# Avara editorial design system
## Direction
Contemporary property and lifestyle publication: warm ivory (#F7F5EF), deep forest (#243B31), sage, sand, restrained brass; editorial serif headlines with existing Inter UI font. Large imagery, intentional whitespace, asymmetrical collections and responsive touch targets.

## Scope
CMS-connected homepage, split hero, elevated working search, illustrated collections and neighbourhood mosaic, active listing feed, complete planning tools, shared design primitives and quiet Property OS GitHub reference. Premium navigation and footer, directory and detail hero, consistent tool and listing surfaces. Original vector artwork is conceptual, not factual views or listing photos. Existing external illustrative hero photo retained with local vector fallback; replace with approved local photography before launch and review usage rights. No fabricated properties or ratings. Reduced motion and visible focus. Existing auth, Mongo APIs and published snapshot preserved.

## QA
CI lint/typecheck/build and calculator/SQL tests must pass. Inspect homepage at 360, 768, 1024 and 1440px; test search, CMS visibility and draft vs public, listing real/empty/error states, keyboard focus, reduced motion, text contrast and long CMS copy. Check /explore, five neighbourhoods, /listings and tools pages; verify mobile nav and admin/owner menus. Browser acceptance and local photo approval remain required.
