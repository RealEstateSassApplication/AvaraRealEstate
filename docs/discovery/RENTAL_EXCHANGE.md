# Rental exchange
Public landing /rentals is discoverable and links to existing room listings, private request form and private owner/tenant views. Tenants opt in to owner matching, can refresh existing matches, close or fulfil and stop sharing. Owners of active listings see only matching criteria, can send one offer per property, and the requester sees the linked listing and uses the existing authenticated enquiry flow. No public request profiles, emails, phone numbers or private notes. Existing requests default private; owner matching limited to 60 days, 200 recent requests and 100 owned active listings; tenant candidate search limited to 500 recent candidates, 30 results. These are bounded pilot limits rather than exhaustive search. No auto-email/WhatsApp or real-time chat; no payment or guarantee. Offers are stored within the Mongo document and optional notifications are best-effort. New optional fields require no destructive migration; verify indexes and existing schema in staging. Legacy PATCH criteria editing is replaced by safe lifecycle operations; create a new request for changed criteria. Review input and access controls in live integration testing; enforce per-account quotas with atomic rate limits before scale. Next: edit criteria, response messaging with moderation/block/report, opt-in notification preferences, expiration renewal, analytics and supply onboarding.
