# Avara Connect
A private property-linked text conversation between the authenticated seeker and the owner of an active listing. Starting an enquiry creates one deterministic thread per property, seeker and owner; opening an existing thread does not resend the initial message. Both participants see their own inbox and can reply. No automatic sharing of account email, phone or other contact information; legacy notification records are not migrated or erased. A participant can block future sends and undo only their own block. Plain text only; no links rendered as HTML, attachments, payments or external messaging. Inbox loads latest 100 threads and last message per thread, explicit refresh (not realtime). Maximum 100 messages per thread, 2,000 chars each, 30 message attempts per account/day; no silent truncation. Existing historical participants retain access even if a property changes status or owner. Limits are pilot design, not end-state. Add retention policy and TTL index for daily limits, report/moderation queue, notification linking, read receipts, cursor pagination, push updates and account-level abuse prevention before broad launch. Test Mongo authorization and mobile UX in CI, verify staging before production. No claim of end-to-end encryption.
