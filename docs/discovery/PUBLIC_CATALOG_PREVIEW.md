# Public PostgreSQL catalog preview
Set AVARA_PUBLIC_CATALOG=postgres-preview, SUPABASE_URL and SUPABASE_PUBLISHABLE_KEY only on an authenticated Vercel preview branch. Do not configure MONGODB_URI or any privileged Supabase key for this preview. It uses public RLS grants and real active rows; empty inventory is a successful 200 with zero results, not a fallback listing. The live Avara project contains zero published records. Production remains disabled by the flag guard. Main listing GET, detail, curated collections, agent inventory, and comparison/map feed share the same PostgreSQL table. No precise coordinates, featured status or owner identity are available in the initial schema; these must not be invented. The preview is for browsing only, not a complete identity/manager/payment migration. Core property mutations reject preview writes. Do not expose public production traffic until the remaining private routes, auth, security audit and storage are implemented and verified.
