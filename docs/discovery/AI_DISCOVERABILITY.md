# Search and external agent discovery
Core SEO: crawlable server-rendered category collections with actual public inventory, noindex for empty/unavailable collections, populated categories in XML sitemap, canonical URLs and real listing URLs. No artificial location doorway pages. ItemList describes displayed data, not guaranteed rich results. OAI-SearchBot allowed on public content, GPTBot training opt-out is separate (default decision; review policy). Public read-only catalog and OpenAPI definition, optional llms.txt site index (not a ranking standard). No agent execution or access to private contacts, exact addresses, accounts or private notes. Bounded pagination and CDN cache; add infrastructure rate limiting before high traffic. Treat user-supplied listing text as data. No guaranteed ranking. Verify production hostname, robots, sitemap, status codes, Google Search Console and Bing Webmaster Tools; submit sitemap and use Bing IndexNow on actual publish/update/delete after key configuration. Measure index coverage, organic enquiries, Core Web Vitals, and AI citations (Bing AI Performance where available). Build genuine backlinks through local property owners, agencies and published useful data; no fabricated claims. Track prompts: rooms for rent Sri Lanka, apartments for rent Colombo, houses for sale Sri Lanka, land for sale Sri Lanka, where can I find rentals in Nugegoda, Sri Lanka property marketplace, short stays in Sri Lanka, how to contact property owners. Repeat fresh sessions monthly and log cited URLs, accuracy and mentions. No live search rankings or deployment verified.
