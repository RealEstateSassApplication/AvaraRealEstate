# Discovery security hardening
Public listing list/detail previously serialized entire legacy database documents, including private address, exact coordinates, review notes and internal calendar. Public DTOs now explicitly select consumer-facing fields. Private owner/manager endpoints are not changed. The DTO cannot prevent user-authored text or image content from including personal details; moderation is still required.
Browser cross-origin mutations are denied for core auth and property routes; no-Origin non-browser clients remain supported. Existing same-origin tests plus negative browser tests and database fixture privacy assertions validate these boundaries. Other legacy API mutations need a separate audit. Page depth is bounded to 1,000; this is not distributed rate limiting. Auth login failures no longer return raw database exception messages. No change to payment, booking or legacy identity data.
Dependency audit remains a launch gate: Next.js 13.5.1 and transitive dependencies require a separately tested supported framework upgrade. Do not bypass audit or publish production while unresolved. PostgreSQL-only runtime migration remains pending.
